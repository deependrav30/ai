# RAG (Retrieval-Augmented Generation) Module

This module will handle document ingestion, chunking, embedding, vector storage, and retrieval for the agent system.

## Subfolders
- `ingestion/` — Document parsing, OCR, and chunking
- `embedding/` — Embedding and vectorization logic
- `retrieval/` — Querying and top-k retrieval
- `utils/` — Shared utilities
